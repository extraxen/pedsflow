# PedsFlow v19.3.0 — PCCU Sedation Update

## Home screen
- Removed the version labels from the right side of the PCCU and ED/PICU cards.
- Cards now show only the navigation chevron when no useful status label is needed.

## PCCU: Sedation, Analgesia & Paralysis
New procedure-first topics:
- Sedation by procedure
- Intubation / RSI sedation
- TBI sedation & neuroprotection
- Lumbar puncture sedation

Expanded medication monographs:
- Fentanyl
- Ketamine
- Midazolam
- Dexmedetomidine
- Propofol
- Etomidate
- Rocuronium
- Succinylcholine
- Cisatracurium (Nimbex)

Each expanded medication entry includes:
- Clinical role
- Typical pediatric reference doses
- Major adverse effects
- Practical cautions/pearls
- Monitoring considerations
- Source/local-verification reminder

## Navigation
- Added a SEDATION emergency shortcut in PCCU.
- Intubation shortcut now opens the dedicated RSI sedation pathway.
- Added related links between TBI, lumbar puncture, RSI, and relevant medication pages.

## Safety
This remains bedside decision support, not an automatic prescription.
Local PCCU/anesthesia/pharmacy protocols remain authoritative for dosing, concentrations,
credentialing, and monitoring requirements.
