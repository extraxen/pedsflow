# PedsFlow 9.1 Release Notes

## Added

- Medication favourites
- Recently viewed medications
- Medication quality/completeness dashboard
- Direct medication links from admission-plan treatment and order text
- Backup and restore for:
  - admission-plan favourites and history
  - medication favourites and history
  - personal notes
  - edited plan sections
  - edited treatment sections
  - algorithm library data
- Version 9.1 interface attribution

## Deliberately not added

- No patient-weight toolbar
- No automatic patient-specific medication calculations
- No new unvalidated medication-dose generation

## Backup privacy

Do not store or export patient names, identifiers, photographs, or protected health information.
