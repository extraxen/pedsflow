# PedsFlow 9.0 Release Notes

## Major upgrades

1. Admission plans expanded from 100 to 130.
2. Calculator suite expanded from 8 to 20.
3. New Antibiotics & Organisms module.
4. Additional high-use medication dose sections from IWK, CHEO and the uploaded historical PCCU card.
5. Home dashboard updated for the new modules and Version 9.0 attribution.
6. Data schema and project assets preserved for GitHub Pages and offline Flutter web builds.

## Not yet complete

- The 300-medication catalogue is not a claim that all 300 monographs are equally complete.
- Some entries remain partial and visibly require local verification.
- Antibiotic selections must be reconciled with the current LHSC antibiogram and local order sets.
- Newly added admission plans require local clinical review before any public clinician-facing commercial release.
